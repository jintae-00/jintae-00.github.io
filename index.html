From Instruction to Motion: Real-Time Language-Grounded Navigation on a Quadruped Robot

Jintae Park* and co-authors (author list withheld during double-blind review)

A user's constraint and a vision-language model's read of a scene rarely make it all the way to the robot's wheels or legs. Here the VLM, prompted with the user's instruction, breaks the scene into a few judgments that matter for motion: which surfaces may be walked on, how much room each object deserves, which way the goal lies, and where a gap is wide enough to pass. Expert detection and segmentation models pin every judgment to pixels, the results are fused into one compact map, and that map both conditions lightweight trajectory decoders and scores each candidate they propose. Because the map is refreshed from the live frame while the slower VLM reasoning catches up, the robot stays aligned with a moving scene. The system runs in real time on a quadruped, outperforms navigation foundation models and VLA baselines in simulation and on campus, and a single new sentence from the user reroutes it without retraining.

ReDesign: Recovering Editable Design Structures from Images via Agentic Decomposition

Jooyeol Yun*, Jintae Park*, Hyesu Lim, Junha Hyung, Hyungjin Chung, Jaegul Choo

A flat image is a dead end: once the design file is lost, you cannot move an element, recolor a shape, or fix a typo. ReDesign grows the design back. A vision-language controller expands an editable layer hierarchy as a tree, coarse to fine, choosing tool-backed actions (text extraction, multi-layer decomposition, connected-component labeling, detection and segmentation, vectorization and typography) and verifying every step until each element is atomic. Text layers, vector shapes, and grouped elements come back editable from a single image. We release Figma-909, a benchmark of 909 real Figma Community designs, to evaluate both reconstruction accuracy and editability.

ODPG: Outfitting Diffusion with Pose Guided Condition

Seohyun Lee*, Jintae Park*, Sanghyeok Park

Virtual try-on without explicit garment warping. ODPG encodes the garment, the target pose, and the person's appearance into latent features and injects them into a UNet denoiser through pose-guided attention, so one end-to-end latent diffusion model dresses a person in a new garment at a new pose while keeping texture detail. Evaluated on FashionTryOn and DeepFashion.
